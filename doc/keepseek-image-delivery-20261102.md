# 图像生成与整图修改交付记录

日期：2026-11-02（Asia/Shanghai）。工程基线 `6c5246e`，版本仍为 `0.5.0`。本次没有提交、推送、打包或发布；原有 `.vscode/settings.json` 改动保留。

## 用户路径与实施结果

代码已提供：命令菜单“生成图片” → 独立账号／模型及单张参数 → 文生图或明确选择一张图片整图修改 → 原会话独立任务卡 → 持久结果、只读放大、相同参数再生成、以结果继续修改 → 选择项目路径 → 二进制 ChangeSet 预览与用户 Apply → read-back → Revert。图像草稿不发送或清空聊天草稿；图片任务不使用文本 Agent 的 busy 锁。

首期适配器为标准 OpenAI Images API，模型 `gpt-image-2.5-sunburst`，只接受明确配置的 `https://api.openai.com/v1`。不是将 Qwen/DashScope 文本兼容地址拼接成图片接口。实现包括 JSON generation 和单张原图 multipart edit；接口契约由自动化验证，真实付费调用未执行。

## 关键实现

- 账号／能力：人工模型、发现缓存及兼容读取贯通；图像选择独立，纯图像模型不能用于文本 Agent。`package.json` 仅增加两个图像选择配置项，没有版本变更。
- 任务／许可：不可变 canonical 规格、动作防重、一次性内存 permit、提交前持久 claim、跨宿主互斥与 revision。重复动作可直接查询既有任务，即使原来源随后已删除；恢复不会创建新付费请求。
- 状态／取回：区分明确失败、提交未知、本地停止、已生成待保存与已保存。诊断 request ID 尽早持久化；它不是远程查询句柄。原结果暂存／入库失败可以重试本地保存，迟到成功保留。
- 资产／隔离：字节内容寻址、hash 与所有权校验、配额、单会话专属资源投影；图片不通过进度消息传输，不进入文本历史／checkpoint／replay。会话切换前持续撤权，拒绝迟到异步刷新重新授权旧目录。历史每页 50 项，累计统计覆盖全部任务。
- 写项目：`binary_image_v1` 绑定 URI、操作、base/result 身份、MIME、尺寸及资产引用。复用既有 preflight、journal、原子替换、read-back、恢复、Discard／Revert。模型审批／delegate 均不能替代用户图片确认；批量确认后复核完整草案集合。
- 费用：保存版本化 USD 分类 token 计价及真实 usage；缺失不能核算时保持未知。每个手动图像任务独立预算域，沿用 `agent.maxCost` 数值；正限额缺乏可信总费用上界时在提交前阻止。不混入文本参考费用，不跨币种相加。
- UI：中文／英文、参数能力约束、单图导入、草稿恢复、稳定动作重试、分页、结果操作、键盘焦点、懒加载与异步解码。

## 兼容性与保留风险

旧账号、旧发现缓存、纯文本草案及会话格式保持可读；新增图像字段使用明确 normalize，损坏的新类型不降级为旧文本修改。没有新增 Agent 图像工具，也没有改静态 system prompt、三协议工具集合或协议版本。

同步接口没有本适配器可用的远程任务查询／取消能力。提交后断网或响应字节持久化前退出，可能已收费却无法取回；保留未知记录，不自动重发。在整个本地存储都失败且进程随后退出时，不能承诺保存同步响应。

原始图片与预览副本共同计入 512 MiB；待入库结果暂存与二进制审核预览各有 128 MiB 上限。单图 20 MiB、4,000 万像素、单边 16,384；PNG 解压上限 160 MiB；拒绝动画和交错 PNG。JPEG/WebP 做结构、尺寸和容量检查，未引入完整原生熵解码器，也不宣称视觉内容验收。保守保留、无自动垃圾回收；达到上限后明确阻止新增，不猜测删除引用。
