# Composer 输入区复刻规格（技术栈无关）

本文件把 KeepSeek 侧边栏最下方输入区的**行为契约**整理成可移植的实现规格，供在其他前端技术栈中复刻同一组件。

- 依据源码：`src/webview/input/**`、`src/webview/richTextShortcuts.ts`、`src/shared/i18n.ts`（`sendShortcutHint*` 等文案）。
- 本文件只描述行为与数据契约，不依赖 DOM id、不依赖 VS Code Webview 消息名。
- 原文中出现的组件内部类名仅作对照，复刻时可用任意命名。

---

## 0. 交付目标

实现一个独立可运行的聊天输入区组件（Composer），用于向 AI 编程 Agent 提交任务。由三部分组成：

1. 富文本输入区（可插入不可编辑的"引用胶囊"）
2. 下方工具栏（引用、命令菜单、执行方式、状态提示、用量指示、发送/停止）
3. 由工具栏或输入触发的浮层（引用选择面板、命令菜单、执行方式菜单、用量详情对话框）

要求：组件化、状态驱动、可测试；提交时对外输出结构化 payload，不把文件内容拼进字符串里假装引用。

### 范围

必须实现：

- 输入与编辑、引用胶囊
- `@` / `$` / `+` 三个引用入口
- 拖拽导入
- 命令菜单
- 执行方式切换
- 状态提示
- 用量圆环与用量详情
- 发送/停止
- 忙碌态降级
- 键盘与无障碍
- 提交 payload 组装

不需要实现：消息列表、会话持久化、模型调用、审批执行、主题系统本身（只需消费 CSS 变量）。

## 1. 视觉与结构规格

输入区卡片为纵向 flex 布局，自上而下：

| 区块 | 说明 |
| --- | --- |
| Skills 条 | 默认隐藏；有激活 Skill 时显示「使用中：」标签 + 可换行的 Skill 胶囊列表 |
| 富文本输入区 | 可编辑、多行、自动增高，最大高度 200px，超出内部滚动；空前显示占位文案（示例"描述要构建的内容"），占位单行省略 |
| 模型切换状态行 | 默认隐藏；切换模型需等当前轮结束才生效时显示一行灰字 + 「取消待切换」按钮 |
| 工具栏左组 | `+` 引用、`/` 命令、执行方式按钮、状态文字 |
| 工具栏右组 | 用量圆环、发送/停止按钮 |

尺寸基线（可按设计系统调整，但相对关系需保持）：

- 卡片最小高度约 116px，圆角 6px，边框 1px，`focus-within` 时边框高亮
- 输入区最小高度 74px（独立时 56px），内边距 4px 4px 2px
- 工具栏高度约 30px，左右自定义内边距
- 图标按钮与发送按钮均为 26×26，圆角 6px
- 输入区字号 13px、行高 1.45、`white-space: pre-wrap`、`overflow-wrap: anywhere`
- 占位文案 12–13px 级别、`pointer-events: none`、`white-space: nowrap` + 省略号

## 2. 富文本输入区（核心）

### 2.1 编辑能力

- 支持多行文本输入、粘贴、撤销、选择；不提供任何富文本格式化（无加粗/斜体/标题）。
- 粘贴一律降级为纯文本，保留换行。
- 输入内容进入 DOM 后立即清洗：只允许纯文本节点、软换行、块级容器（div/p/li/ul/ol）以及两类引用胶囊；其他标签一律"拆壳"保留文字、清除全部内联样式与属性；注释节点直接删除。
- 自动增高：高度自适应，超过 200px 封顶并内部滚动；出现滚动条时不得导致每次输入的视图跳动（显式保持 `scrollTop`）。
- 空判定：既无文本、也无任何引用胶囊/Skill 胶囊时才算空。空状态下若 DOM 残留空白节点，归一化为完全空，并把光标置于开头。

> 验收锚点：验收清单第 1、2、12 条。

### 2.2 引用胶囊（不可编辑行内块）

- 两种胶囊：文件/目录引用、Skill 引用。
- 胶囊是行内块，`contenteditable=false`，光标不可进入、不可逐字编辑；退格一次删除整个胶囊。
- 外观：小圆角浅底、1px 边框、12–14px 字号、单行不换行、超长省略；图标 + 文本；目录胶囊用绿色系语义色，Skill 胶囊用蓝色系 + 等宽字体。
- 胶囊文本由标签重建函数生成，"重新渲染标签"必须幂等（Skill 名称/描述更新后能刷新已有胶囊）。
- 单击胶囊不移动光标，而是触发对外事件（打开文件 / 打开目录 / 打开 Skill）；双击不得重复触发。点击时必须阻止默认行为。
- Skill 胶囊提供 `tabIndex=0`，Enter/Space 触发打开；胶囊内部的按钮子元素不重复处理。

## 3. 三个引用入口

三个入口必须共用同一份数据源与插入函数。

### 3.1 `@` 行内触发（文件/目录）

- 光标前存在 `@`，且 `@` 与光标之间没有空格、换行或 `<`/`>`，即视为触发；取 `@` 之后的文本作为查询词（大小写不敏感、trim、子串匹配）。
- 触发即打开引用面板，并把 `@查询` 所在范围记为"待替换范围"。
- 查询词变化时高亮项重置为第一项。
- 触发消失（删掉 `@`、光标移走、只读状态）则关闭面板；关闭时清空面板内容与 aria 状态。

### 3.2 `$` 行内触发（Skill）

- 规则同上，但 `$` 还要求前一个字符为空（行首或空白），避免误触。
- 在 Markdown 代码围栏（``` 或 ~~~ 三段以上）内不触发 `$`。
- 面板按 Skill 来源分组（组标题为来源名），只列出"启用 + 用户可调用 + 无不可用原因"的 Skill。
- 选中效果：把该 Skill 加入活跃 Skill 列表、在输入区插入 Skill 胶囊，并同步 Skills 条（两处一致）。

### 3.3 `+` 按钮

- 点击打开引用面板，来源标记为按钮；不插入 `@` 字符，光标位置保留，关闭后焦点回到输入区。
- 按钮展开时呈激活态、`aria-expanded=true`。
- 忙碌时禁用，title/aria-label 改为"运行中不可引用文件"。

### 3.4 拖拽导入

- 整个卡片是投放区；拖入时卡片与输入区显示虚线高亮 + 高亮底色。
- 使用进入/离开计数避免子元素造成闪烁；离开到外部才取消高亮。
- 松手时把光标定位到鼠标释放点对应的文本位置（无法定位则末尾），再插入引用。
- 识别优先级：真实文件路径 → `text/uri-list` → 编辑器 URI 列表 → `text/plain` 中的独立 `<路径>` / `file:` URI / 独立绝对路径（每行一条，忽略 `#` 注释行）。
- 按"文件 + 行号范围"去重，同一次拖拽重复项只插一次。
- 拿不到路径的文件：按大小上限（示例 200KB，可配置）读取内容，交给上层以"导入文件"方式插入引用；超限提示"文件过大"，读取失败提示"无法读取"，完全拿不到引用提示"缺少引用路径"。

### 3.5 插入规则（文件引用）

- 插入片段两端各加一个空格，多个引用之间用软换行分隔。
- 光标处于未闭合的 Markdown 代码围栏内（按行解析围栏开合）时，不插入胶囊，改插纯文本引用，例如 `<file:///path#L10-L20>`。
- 每次插入后：光标落到插入内容之后、保存选区、刷新空状态与按钮、派发一次 input 事件。
- 状态栏给出简短反馈（示例"已插入 3 个文件引用"）。

## 4. 引用选择面板

- 位置：贴输入卡片上方（`bottom: 100% + 6px`），左右与卡片对齐；圆角 8px、带阴影、最大高度 `min(50vh, 420px)`、内部列表滚动。
- 结构：头部（标题 + 数量）→ 列表（每项：主名 + 副信息）→ 空态文案。
- 标题随来源变化："引用文件" / "使用 Skills"。数量显示可选项数；加载中显示"加载中"，错误显示错误文案。
- 项样式：两行（主名加粗、副信息灰色小字、单行省略）；目录名绿色、Skill 名蓝色等宽并带图标；悬停/聚焦/高亮共用同一视觉；禁用项半透明且无高亮底色。
- 特殊首项「选择外部文件」：仅在来源为按钮、或 `@` 后无查询词时出现；`$` 来源永不出现。选中它：删除待替换的 `@query` 文本、关闭面板、请求上层弹出系统文件选择器。
- 数据加载：面板首次打开时请求资源列表，用请求 ID 丢弃过期响应；加载中若已有缓存则不覆盖已展示列表。
- 空态文案区分：`@` 查询无结果 / 无可用文件 / `$` 查询无结果 / 无可用 Skill。
- 高亮与键盘：
  - 高亮项在列表内循环移动，保证滚入可视区。
  - 面板聚焦时方向键 / Home / End / Escape 由面板处理。
  - 输入区聚焦时 ↑/↓ 移动高亮、Enter/Tab 确认插入、Escape 关闭并回焦点到输入区。
- 点击面板项用 `mousedown preventDefault`，防止输入区先失焦导致选区丢失。
- 点击面板与 `+` 按钮之外的区域关闭面板（不恢复焦点）；Escape 或选中项关闭时恢复焦点到输入区。
- 忙碌行为：面板保持可见但只读——所有项禁用，Enter/Tab 不再被吞掉（回退浏览器默认），点击给出统一提示。

## 5. 命令菜单（`/`）

- 位置同上；带分组标题的可滚动面板，可放开关、下拉、滑杆等控件。
- 打开：点击 `/` 按钮切换；打开后焦点留在输入区。
- 关闭：再次点 `/`、点击外部、Escape（焦点回输入区）、或任一引用浮层打开（命令菜单与引用面板互斥，后开者关闭前者）。
- 内容分区（业务含义，措辞由产品定）：
  - Skills 区：使用 Skills 入口 + 可折叠 Skill 列表（含按名称过滤输入框与"创建 Skill"入口）。
  - Agent 区：后台任务入口，值为可用脚本名列表，忙碌或有后台任务运行时禁用。
  - Model 区：主模型选择、子代理模型选择（按子代理类型分组）、审批模式选择。
  - 控制类：自动压缩阈值三档（如 70% / 80% / 85%，单选标签页 + 说明随选择变化）、推理强度滑杆（如 Off / High / Max，显示当前值）。
- 每行统一为"标题 + 灰色说明 + 右侧当前值"；展开的下拉列表为同样行条目，当前项打勾。
- 键盘可达性：面板内 ↑/↓ 逐项移动焦点（循环）、Home/End 首尾、→ 展开子列表并聚焦首项、← 收起子列表并回父行、Escape 关闭。对原生输入控件（文本框、数字、范围滑杆、下拉）不拦截方向键。
- 忙碌态：整体只读样式；默认全部禁用，但允许例外放行（模型选择、审批模式在某些条件下仍可切换），由外部状态位控制，不得写死。

## 6. 执行方式切换（N / P）

- 26×26 按钮，标签为单字母：常规 `N`，计划 `P`。
- 悬停显示自绘 tooltip（不用原生 title）：第一行"执行方式：常规"，第二行描述（常规"边分析边推进，适合明确的日常任务"；计划"先产出实施计划，用户确认后再开始执行"）。
- 点击打开上方浮层菜单，两项单选项，选中项显示 ✓ 且带说明。
- 键盘：↑/↓ 循环、Home/End 首尾、Escape 关闭并回焦点、Tab 关闭并按顺序移到下一控件。
- 选择后立即上报 `setExecutionMode` 并关闭菜单。
- 存在"待确认计划工作流"时，tooltip 描述后追加一行提示。
- 三种锁定原因：设置恢复中（`aria-busy`）、设置加载失败、任务运行中（只读）。锁定时按钮禁用、菜单不可打开，点击用状态栏说明原因。

## 7. 语义化表单与提交协议

- 整个输入区是一个 form；Enter 换行、Ctrl/Cmd+Enter 提交（阻止默认）；发送按钮为 submit。
- 提交前置：先清洗 DOM，再序列化；序列化结果 trim 后为空则不提交（但只有引用胶囊时视为可提交）。
- 提交时组装并上报结构化对象：

```ts
interface ComposerSubmitPayload {
  prompt: string;
  sourceId: string;
  modelId: string;
  settings: AgentSettings;         // 由命令菜单控件读取
  references: FileReference[];     // 从文件/目录胶囊读取
  skillIds: string[];              // 从 Skill 胶囊去重收集
}

interface FileReference {
  path: string;
  kind: 'file' | 'directory';
  startLine: number;   // 0 = 未指定
  endLine: number;
  startColumn: number;
  endColumn: number;
}
```

- 提交成功后：关闭所有浮层、清空输入区、清空选区记忆、清空 Skills 条、更新按钮与用量状态。
- 忙碌中提交（如快捷键触发）：不发送，关闭浮层，状态栏提示"任务运行中"，焦点回输入区。

## 8. 序列化规则（DOM → 文本）

必须确定且可测：

- 文本节点原样输出。
- 软换行 → `\n`。
- 块级元素（div/p/li/ul/ol）前后各补一个 `\n`，但不产生连续空行（已以换行结尾则不再补）。
- 文件引用胶囊输出为独立段落：第一行是展示标签（文件名 + 行号范围，例如 `app.ts#L10-L20`），第二行是尖括号包裹的目标（例如 `<file:///abs/path/app.ts#L10-L20>`）；目录引用输出为 `目录名/ <keepseek-dir:绝对路径>`。
- Skill 胶囊输出为 Markdown 链接形式 `[$skill-name](skill.md 路径)`。
- 最终结果去掉首尾空白，换行统一为 `\n`。
- 反向兼容：粘贴或拖入的纯文本若形如 `<...>` 的独立行，要能识别并还原成引用胶囊；含引号、反引号、键值属性、控制字符的不识别，按普通文本处理。
- 行号解析：`#` 后接 `[l]起始行[c起始列][-|:|,][l]结束行[c结束列]`，大小写不敏感；数字小于 1 视为 1；结束行小于起始行时纠正为起始行。
- 只读取最后一个合法的 `#` 片段作为行号，路径部分保持原样。

## 9. 发送 / 停止按钮

- 两个状态：发送（向上箭头）、停止（实心方块），通过 data 属性切换以便测试。
- 空闲：完全空内容时禁用；有文本或有文件引用时可用；仅 Skill 胶囊时禁用（Skill 不带上下文内容）。
- 忙碌：始终可用，主按钮样式从强调色切换为危险色中止样式；点击不提交表单，而是发出中止请求并把状态栏改为"正在停止当前任务..."。
- 标题与 aria-label 随状态在"发送 / 停止"间变化。

---

## 10. 状态提示（工具栏左侧文字）

- 单行、11px、次要色、单行省略、高度约 26px，占两个按钮之间剩余空间。
- 临时消息：显示后约 3 秒自动淡出并清空；有新消息时重置计时器，用序号丢弃过期回调，避免旧计时器清掉新消息。
- 常驻消息（如"正在停止/重连中"）：不自动消失，带呼吸式颜色渐变动画。
- 消息较长（按 UTF-8 字节数判定，约 60 字节以上）时，悬停显示自绘 tooltip 展示全文（可换行、任意断词）。
- 空闲提示文案随平台变化（Mac：Ctrl+Enter 或 Command+Enter；其他：Ctrl+Enter）；忙碌时提示"当前任务运行中，点击停止按钮可中止"。

---

## 11. 用量圆环与用量详情

- 工具栏右侧 26px 圆环按钮，用 CSS 锥形渐变按上下文占用百分比渲染进度弧；悬停 tooltip 显示标题、已用百分比、本次会话 token，以及明细行（本轮缓存命中率、平均或当前模型命中率、本轮 token、轮次数、会话费用、余额等，按数据可得性显示"未记录/不可用"）。
- 阈值着色：达到软压缩阈值 → 警告色；达到强制压缩阈值 → 危险色。
- 点击打开模态"用量详情"：默认聚焦"关闭"按钮，Escape 关闭，关闭后焦点回到圆环按钮；内部含"按来源 / 按类型"两种统计视角切换。
- 忙碌态仍可用。

---

## 12. 键盘、焦点与无障碍

- 输入区：`role=textbox`、`aria-multiline=true`；`aria-controls` / `aria-activedescendant` 在面板打开时指向浮层与高亮项，关闭时移除。
- 选区记忆：输入、按键、鼠标抬起、聚焦、选择变化（仅当焦点在输入区内）时保存 Range；插入、点击工具栏按钮、上层注入内容前恢复 Range。空内容时强制把光标规范到开头。
- 粘贴、拖拽、上层注入都走同一插入函数，保证"清洗 → 插入 → 光标 → 事件 → 视觉刷新"一致。
- 所有浮层支持 Escape 关闭并交还焦点；外部点击关闭时不抢焦点。
- IME 组字中（`isComposing` / `keyCode === 229`）必须完全不拦截任何按键。
- 输入区内默认文本编辑快捷键（全选、删除行、按词移动等）不得被覆盖。
- 发送快捷键：Ctrl+Enter（全平台）与 Command+Enter（Mac）。

---

## 13. 忙碌（busy）态统一定义

一轮 Agent 运行期间：

- 输入区仍可编辑（允许提前起草下一条），但发送按钮表示"停止"。
- `+` 引用按钮禁用；引用面板 / 命令菜单可通过已有入口显示但整体只读；点击或确认引用项给出统一提示。
- Skill 胶囊移除按钮禁用并替换 tooltip。
- 执行方式控件锁定。
- 提交动作被拒绝并提示。

这些必须由一个布尔状态 + 若干"锁定原因"推导，不得在每个控件里各自判断。

## 14. 验收清单

1. 输入 10 行文本，框体在 200px 内增高，超过后内部滚动且输入不跳动。
2. 粘贴带样式的网页片段，落库文本与原纯文本一致，不保留任何样式标签。
3. 输入 `@app` 弹出面板并过滤；↑/↓ 循环、Enter 插入、Escape 关闭并回焦点。
4. 在代码围栏内输入 `$` 不弹面板；插入文件引用时也只插入纯文本。
5. 从文件管理器拖入 2 个文件，光标落在投放点，插入两个胶囊，重复项被去重。
6. 点击胶囊打开对应文件/目录/Skill；双击不触发两次。
7. `/` 打开命令面板，与引用面板互斥；面板内 →/← 展开收起子列表，Escape 回焦点。
8. 执行方式 N/P 切换有 tooltip、有勾选、选择后立即上报。
9. Ctrl/Cmd+Enter 提交，payload 中 prompt 与 references/skillIds 与所见内容一致。
10. 忙碌态下：按钮变停止、引用按钮禁用、提交被拒并提示、Escape/点击关闭浮层仍正常。
11. 空内容 + 只有一个文件引用时发送按钮可用；只有 Skill 引用时发送按钮禁用。
12. 删除最后一个文字字符后光标停在开头，占位文案立即出现。
13. 临时状态消息 3 秒后淡出；期间收到新消息，旧计时器不会误清空。
14. 用量百分比变化时圆环角度变化，警告/危险阈值切换样式，详情对话框可开可关且焦点正确。
